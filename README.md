# LLM Security Homework

Python-скрипт для генерации тестовых сценариев формы регистрации пользователя с помощью локальной модели Ollama.

## Что делает скрипт

Скрипт генерирует заданное количество тестовых сценариев в формате Markdown.

Сценарии включают:
- позитивные проверки;
- негативные проверки;
- тестовые данные;
- шаги;
- ожидаемый результат.

Количество сценариев передаётся при запуске программы.

## Требования

- Python 3
- Ollama
- Модель `llama3.2:latest`
